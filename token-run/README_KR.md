# 토큰 런

Claude Code에서 요청이 실패했을 때, 또는 잠깐 쉬고 싶을 때 즐기는 로컬 ASCII 러너 게임입니다. `@` 커서가 BUG·429·TIMEOUT 장애물을 점프로 넘습니다. [English](README.md).

## 설치와 실행

연결되어 있을 때 먼저 설치하고 로드하세요. 이후 게임은 네트워크나 모델 호출 없이 동작합니다. 함수 훅·Client API는 **Claude Code 2.1.296·2.1.299·2.1.300·2.1.301**의 엔진 테스트와 **2.1.296·2.1.301**의 실제 터미널에서 검증했습니다. Mods를 지원하지 않는 구버전에서는 사용할 수 없습니다.

```sh
claude plugin marketplace add YeonwooSung/my-claude-code-mods
claude plugin install token-run@my-claude-code-mods
# 또는 호환되는 바이너리로 현재 저장소에서 실행:
CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1 claude --plugin-dir ./token-run
```

```text
/token-run
/token-run help
/token-run close
```

메인 턴이 오류로 끝나면 입력창 위에 게임 진입 버튼이 나타납니다. 클릭하거나 `/token-run`을 입력하면 넓은 전체 화면에서는 대화 옆, 그 외에는 입력창 위에 패널을 엽니다. 입력한 명령·클릭에 대한 응답으로만 포커스를 요청합니다. 포커스가 넘어오지 않으면 게임을 클릭하거나 `ctrl+x tab`을 사용하세요. 대화와 입력 중인 프롬프트를 바꾸지 않습니다.

## 조작

| 키 / 버튼 | 동작 |
|---|---|
| 트랙 클릭 / Space / ↑ / Jump | 시작과 점프. 공중에서는 추가 점프 불가 |
| R | 같은 코스로 재시작 |
| P | 일시정지 / 재개 |
| Q | 게임 닫기 |
| Esc | 입력창으로 포커스 복귀. 비어 있는 대기 입력창에서 다시 Esc를 누르면 패널 닫기 |

게임에 포커스가 있을 때만 키를 받습니다. Ctrl·Meta·Shift 조합은 무시하고 전역 단축키를 등록하지 않습니다. 트랙이나 Jump를 클릭해 게임에 키보드 포커스를 주세요. Esc는 엔진이 처리합니다. API에서 Client의 포커스 이탈을 알 수 없으므로 자동 정지하지 않습니다. 작업으로 돌아가기 전 P로 정지하고, P로 재개하세요. 닫았다가 다시 열면 새 게임입니다.

도킹 패널과 인라인 패널 사이로 전환되면 Client가 다시 생성될 수 있습니다. 메모리 체크포인트로 복구하며 정지·재시작 상태는 즉시 저장합니다. 진행 중에는 약 1초의 게임 시간까지 되돌아갈 수 있습니다. 전환 후 트랙이나 버튼을 클릭해 포커스를 다시 주세요. 닫으면 체크포인트를 지웁니다.

좁은 패널에서는 상태를 `LOCAL`·`SAVE!`(기록 저장 경고)·`BACK:Esc`(응답 복구)로 줄여 표시합니다. 게임오버·재시작·일시정지 안내는 먼저 보여줍니다. Q는 즉시 닫고 이미 접수한 기록 저장은 이어서 마칩니다.

최소 24열·8행이 필요합니다. 작아지면 크기 안내를 보여주고 게임 진행을 멈춥니다. 점수는 살아남은 초 단위이며 충돌하면 고정됩니다. 최고 기록은 플러그인의 로컬 저장소에 저장되어 같은 저장소를 사용하는 다른 세션에서도 이어집니다.

매초·충돌·Q 종료 시 기록을 저장합니다. Esc나 엔진의 닫기 버튼에서는 최신 체크포인트까지 저장됩니다. 저장 실패 시 경고를 보여주고 게임과 메모리 최고 기록은 유지합니다. 별도 프로세스들이 동시에 저장할 때의 동기화는 보장하지 않습니다.

터미널과 Desktop을 지원합니다. VS Code 채팅·모바일·비대화형 실행에서는 게임을 실행하지 않습니다. 설문이 진입 안내보다 우선하며, 게임에서 포커스를 가져갈 수 있습니다.

## 네트워크 감지 범위

검증한 엔진 API에는 OS 네트워크 상태 이벤트나 읽을 수 있는 재시도 표시가 없습니다. 따라서 “요청 실패”를 관측해 안내하며, 서버·인증·컨텍스트 오류에도 안내가 나타날 수 있습니다. 재시도 중이 아닌 턴 실패 후에 표시합니다. 이를 모두 오프라인이라고 단정하지 않습니다.

별도 연결 확인 요청이나 자동 재시도를 추가하지 않습니다. 이후 메인 모델 응답이 도착하면 작업 복귀 안내를 표시하지만 게임을 강제로 끝내지는 않습니다. 서브에이전트의 요청 상태는 안내에 영향을 주지 않습니다.

## 개발과 검증

```sh
npm test
npm run typecheck
CLAUDE_BIN=/path/to/claude-2.1.301 npm run test:adapters
CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1 /path/to/claude-2.1.301 plugin test token-run
/path/to/claude-2.1.301 plugin validate token-run
```

타입 검증에는 해당 엔진의 `.claude-plugin/types` 로컬 선언이 필요하며 다른 모드처럼 Git에서 제외합니다. 런타임 의존성은 추가하지 않습니다. 순수 테스트는 물리·저장 실패/경합·요청 세대·화면 크기를, 실제 엔진 테스트는 터미널/Desktop Client의 키·버튼·프레임·부모 Pane 비포커스 상태의 입력·명시적 정지·리사이즈 복구·기록·세션 전환을 검증합니다. 실제 화면의 픽셀 캡처 검증은 포함하지 않습니다.


## 실제 터미널 검증 (선택)

macOS/Linux에서 임시 설정·가짜 API 키·접속이 거부되는 로컬 API 주소로 CLI를 격리 실행합니다. 실제 키·마우스 입력, 프레임, 리사이즈, 요청 실패 진입, 프로세스 재시작 후 기록을 검증합니다. 계정이나 시스템 네트워크 설정을 사용·변경하지 않습니다. Python 의존성은 QA 전용입니다.

```sh
python3 -m venv /tmp/token-run-qa
/tmp/token-run-qa/bin/pip install -r token-run/qa/requirements.txt
/tmp/token-run-qa/bin/python token-run/qa/pty_smoke.py --claude-bin /path/to/claude-2.1.301 --artifacts /tmp/token-run-smoke
# --combined를 추가하면 7개 모드를 함께 로드합니다.
```

2.1.296·2.1.301 단독 실행과 2.1.301의 7개 모드 동시 실행에서 각각 19개 검증 지점을 통과했습니다. ANSI 출력·해석한 화면·result.json을 남깁니다. Desktop 네이티브 GUI는 확인하지 않았으며 엔진 렌더 트리만 검증했습니다. 상세 결과와 한계는 [검증 보고서](../docs/verification/2026-10-17-token-run.md)에 기록했습니다.

검사 참고: `qa/pty_smoke.py`는 PATH·홈 경로·LANG·TERM 등 고정된 OS 메타데이터만 전달하고, 설치자의 전체 환경변수나 API 토큰을 복사하지 않습니다. 별도 임시 설정과 예시 키, 연결이 거부되는 로컬 API 주소를 사용하는 선택적 테스트입니다. 테스트의 `command()`와 `complete()`는 엔진이 제공하는 고정 `/token-run` 명령과 가상 턴 종료를 호출하며 다른 플러그인이나 셸을 실행하지 않습니다.
